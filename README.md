## currently building

Three projects living in the same corner of my attention while I job hunt, in no particular order:

1. **[Animu](https://github.com/yukjidam/Animu)** — *Flutter · Firebase*
   An anime tracker with reviews, threads, and a notification system, built because MAL still looks like it was designed by someone allergic to dark mode. Slowly fixing that between applications.

2. **[PlantoDex](https://github.com/yukjidam/PlantoDex)** — *Flutter · REST API*
   A Pokémon Go style app, except the pokémon are real plants and I'm the one doing the catching. Currently locked in an ongoing fight with a very stubborn API.

3. **[Ruta](https://github.com/yukjidam/Ruta)** — *Flutter · Firebase · Maps*
   A motorcycle touring app for riding solo or with a crew, started right after I got my first bike. The newest thing keeping me up at night.
